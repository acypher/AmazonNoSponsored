# Amazon Results No Sponsored

See Amazon.com search results without sponsored placements. This extension hides sponsored product cards, carousels, video ads, brand banners, and other marked sponsored sections on Amazon.com search result pages.

It works with Amazon's usual sort options and with other extensions that reorder the results. Sponsored items are hidden in the page rather than removed from its underlying structure. Organic products remain visible.

The extension runs only on Amazon.com search result pages. It does not collect, store, or transmit personal data, and it has no analytics or accounts. If Amazon changes how it labels sponsored placements, some ads may reappear until the extension is updated.

Independent extension; not affiliated with Amazon.
